# stable 1.1.1: the narrow window and the 1.1 bugs

Status: built, 2026-10-21. Made on `release/1.x`, merged forward into `main`. The roadmap's 1.1.1 line: Studio below 1280 px, the board difficulty `window.prompt`, and the other 1.1 bugs the audits named — here, the ones beta.3–beta.4 fixed on `main` that stable has too. Nothing here is a feature; every change is one a stable operator would call a bug.

## What changes

1. **An opened row is seen below 1280 px.** The library tabs' detail aside is `hidden` under `xl`, so at 1100 px opening a team, question or operator shows nothing (the e2e suite's failures at 1100 px). Below `xl` the aside opens **over the list's right edge** — the same panel, a surface with a shadow, as wide as 22rem or the window — with a **Close** that goes back to the list. At `xl` and above nothing changes.
2. **The difficulty edit is a dialog** (`DifficultyDialog`, as on `main`): the number 1–100 and the scope (*This game only* · *Apply to original*) in one frame; the buttons judge the value when pressed. No `window.prompt`.
3. **"Still used by a a recipe board"** reads once: the confirm says what the host says.
4. **A theme colour is a swatch**: a team colour that is a theme token (the Demo's) shows as a checked *Theme colour* swatch and an empty *Colour code* field in the editor, and as a swatch and *Theme colour* in the detail — never the raw `var(--state-…)` text.
5. **Dialog actions stay inside the frame**: footers wrap.
6. **Plays are numbered**: *Play 1*, *Play 2*… by start time, the id as a tooltip.
7. **The question editor writes once**: the question and the domains whose membership it changes in one `catalog_upsert_many`, so a refused membership leaves no saved question behind.
8. **A refusal's text is words**: an inline notice drops the routing path the host's message starts with.

## Non-goals
No workspace, copy, picker or bulk-bar work (Beta). No host change beyond what (7) needs (none: `catalog_upsert_many` exists in 1.1).

## Merging forward
`main` already has (2)–(8) in their Beta form; on the merge its versions win, and (1) is taken as written.
