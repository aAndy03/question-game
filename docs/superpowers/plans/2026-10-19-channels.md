# Release channels (A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship *questiongame Beta* beside *questiongame*, with separate data, a first-launch choice to start empty or copy the stable library read-only, per-channel publishing and update checks, and a version bumper. Nothing is tagged.

**Architecture:** One `Channel` value, decided at boot from the identifier (plus an e2e-only env var) and managed as Tauri state, is the only thing every channel-dependent path reads. The stable library is never opened by SQLite in place: `stable_copy.rs` byte-copies it into the Beta folder and the host compacts that copy. CI routing and version arithmetic are pure TypeScript modules the workflow and `scripts/version.ts` call.

**Tech Stack:** Rust (Tauri 2, rusqlite in the host, `semver`), React 19 + HeroUI v3 (Studio), vite-node scripts, vitest, WebdriverIO e2e, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-19-channels-design.md`

**Tests:** `docs/superpowers/plans/2026-10-19-channels-tests.md` — 170 ids proposed by Sonnet, with the decisions on its flags. Each task lists the ids it owns; every **[MUST]** id lands with its task, the rest unless the list says why not. Where a step below and the list differ, the list's decision table wins.

## Global Constraints

- Identifiers: stable `org.questiongame.desktop`, Beta `org.questiongame.beta`, dev `org.questiongame.app`, e2e `org.questiongame.e2e`. Beta product name `questiongame Beta`.
- Env vars, honoured **only** by the e2e identity: `QUESTIONGAME_E2E_CHANNEL` (`stable` default | `beta`), `QUESTIONGAME_E2E_STABLE_DIR`.
- Beta writes **not one byte and no new file** in the stable folder. `RELEASE_IDENTIFIER` / `org.questiongame.desktop` appear in `crates/app/src` only in `identity.rs` and `stable_copy.rs`.
- Meta row `beta.welcome_seen`. Command names: `beta_welcome_get`, `beta_welcome_done`, `beta_copy_stable_library` — Studio-only (`guard`), in `packages/contract` and `generate_handler!`.
- Welcome copy, EN and RO, with the language toggle *What's new* uses. RO: *"Aceasta este questiongame Beta. Are propria bibliotecă, separată de questiongame. Nimic din ce faci aici nu îți schimbă biblioteca stabilă."* — **Copiază biblioteca mea stabilă** / **Începe de la zero**; *"Închide mai întâi questiongame, apoi copiază."* — **Încearcă din nou**. EN: *"This is questiongame Beta. It keeps its own library, separate from questiongame. Nothing you do here changes your stable library."* Buttons **Copy my stable library** / **Start empty**. Refusal while stable runs: *"Close questiongame first, then copy."* with **Try again** / **Start empty**.
- Tags: `vX.Y.Z` → stable, `prerelease: false`, release *questiongame vX.Y.Z*; `vX.Y.Z-beta.N` → `--config crates/app/tauri.beta.conf.json`, `prerelease: true`, release *questiongame Beta vX.Y.Z-beta.N*. A tag must equal `v` + `package.json` version. Build-only runs take any version.
- Beta update check reads `/releases?per_page=20`; stable keeps `/releases/latest`.
- No schema change. No tag, no push of a tag, ever, without the maintainer's word; ask before each push.
- Every phase commit carries its docs (`04_ROADMAP.md`, `docs/as-built/<area>.md`, `history.md`), a regenerated `codemap.yaml` with empty `mismatches:`, and the co-author line. CLAUDE.md gets one "which branch?" line, nothing more.
- Data folders `org.questiongame.desktop` and `org.questiongame.app` are not touched by any test or manual check. Ask first.

## Review Focus

1. **A crashed stable left a `-wal`** — the copy must include its committed pages. Test: `stable_copy::tests::copies_a_library_with_a_pending_wal` (Task 8).
2. **A stable that is closed but whose lock file never existed** (fresh install that never ran) — that is "not running", and the lock file must not be created. Test: `stable_copy::tests::no_lock_file_is_not_running_and_creates_none` (Task 8).
3. **The copy succeeds but reopening fails** (disk full, a corrupt stable file) — Beta must come back up on an empty library, never on a half-written one, and say why. Test: `beta::tests::a_failed_reopen_leaves_an_empty_library` (Task 9).
4. **The operator presses Copy twice** (double click, or Try again after success) — the second must be refused because the library now has rows, not copy over it. Test: `beta::tests::copy_refuses_a_library_with_rows` (Task 9).
5. **A stable 1.0.2 build in the wild must behave exactly as before** — `Channel::Stable` changes no update URL, no notice, no boot path. Tests: `update::tests::stable_reads_latest_only` (Task 3), `beta_welcome_get` answers `show: false` on stable (Task 9).

### Task 8: Copying the stable library without touching it

**Files:** Create `crates/app/src/stable_copy.rs`, `crates/app/tests/stable_folder.rs` (the grep test); Modify `crates/host/src/catalog/service.rs` (+ `db.rs` if the helper lives there), `crates/app/src/lib.rs` (`mod stable_copy`)
