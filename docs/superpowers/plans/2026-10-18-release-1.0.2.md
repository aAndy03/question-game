# Release 1.0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 1.0.2 — current dependencies, an opt-in for repeated difficulties on a board, refusals visible from anywhere, an update notice, a one-time *What's new*, and an upgrade that backs the library up before it changes anything.

**Architecture:** Host truth stays in `crates/host` (board rule, backup, version stamps — no `tauri::`); the network check and the URL opener live in `crates/app`; Studio renders. Version stamps are rows in the existing `globals` key-value table, so **no schema migration** this release and a 1.0.1 binary can still open a 1.0.2 library.

**Tech Stack:** Rust (rusqlite, serde, `ureq` + rustls, `semver`, `tauri-plugin-opener`), Tauri 2, React 19, HeroUI v3, TanStack Query, Zustand, vitest, cargo test.

**Spec:** `docs/superpowers/specs/2026-10-18-release-1.0.2-design.md`

## Global Constraints

- Version `1.0.2` in `Cargo.toml [workspace.package]`, `crates/app/tauri.conf.json`, root `package.json` (held by `crates/app/tests/bundle.rs`).
- One phase commit per task on `main`, `P12.5` … `P12.11`, docs in the same commit (`CLAUDE.md`, `docs/v1/04_ROADMAP.md`, `05_STUDIO_DESIGN.md` / `optimized_first_spec.md` where touched). Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Every new settings field: `#[serde(default)]`. Every new command: `#[tauri::command(async)]`, added to `guard` lists only for `main` (never `STAGE_COMMANDS`, never `STATS_COMMANDS` unless read-only and needed).
- New command names added to `packages/contract` command list and `apps/studio/src/host/types.ts`; settings-writing ones to `writesSettings`.
- The webview fetches nothing (`release:check`). Network = `crates/app/src/update.rs` only.
- Licence audit (`npm run build`) must pass without widening `ALLOWED`.
- HeroUI markup: invoke `heroui-react` first. No toasts for anything with an action.
- Copy lives in `apps/studio/src/copy/`.
- GitHub repo: `aAndy03/question-game`. Release URL shape: `https://github.com/aAndy03/question-game/releases/tag/v<version>`.
- Backups: `<app data>/backups/questiongame-<old version>-<yyyymmdd-hhmmss>.sqlite3`, keep **5**.
- Every command takes `now_ms` where it needs time; no clock in the host.

## Review Focus

1. **Boot offline / DNS stall** — the update check must not delay the first window or a command; it runs on its own thread with a 5 s timeout and is silent on any failure. Test in Task 5: `check` with a fetcher that errors returns `Ok(None)` and logs.
2. **Version ordering** — `1.0.10` is newer than `1.0.9`; `v` prefix and prerelease tags (`1.1.0-rc.1`) are handled by `semver`, prereleases ignored. Test in Task 5.
3. **Backup can't be written** (disk full, read-only folder) — the library is not migrated and boot fails loudly through `boot::fail`, naming the folder. Test in Task 2 with an unwritable backup dir.
4. **Switch turned off on a board that now holds repeats** — refused with a path naming the clash, and that refusal is visible from Roster (Task 4's global surfacing). Test in Task 3 (host) and Task 4 (Studio).
5. **Refusal repeated** — pressing Load five times on a broken board shows one notice, not five stacked; fixing the board clears it. Test in Task 4.
